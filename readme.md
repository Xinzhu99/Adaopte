# 🐱 Adaopte 
## site d'adoption des animaux 

### ✨ Fonctionnalités principales

- 🔍 **Recherche dynamique d’animaux** par type et par ville  
  → Le filtrage se fait automatiquement à partir des paramètres d’URL (`URLSearchParams`).
- 🐶 **Affichage des résultats en cartes**  
- ⚠️ **Message d’erreur ou de succès** 
- 🧭 **Navigation claire et responsive**
- 🎨 **Design moderne et cohérent**, basé sur des variables CSS et une mise en page responsive grid/flexbox.
